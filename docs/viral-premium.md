# Viral Premium

Experimental premium editor isolated on `viral-premium-test`.

## Premium layer

- Same fast Viral/Darwin storyboard and verified reaction engine.
- Gemini Scene Composer chooses clean/parallax/text-behind/split-screen.
- Exact Whisper word timings drive kinetic active-word subtitles.
- Selected semantic words receive stronger colour/scale emphasis.
- `rembg` creates transparent foregrounds for 2.5D and text-behind-subject.
- Split screen uses an independently retrieved second comparison image.
- Premium audio supports voice-driven sidechain ducking and planned music drops.
- Premium music is optional: put a royalty-free audio file in `music/`.

## Isolation

Classic, Story, Dynamic and Viral v1 do not call the premium composer,
premium renderer or premium mixer unless Premium is explicitly selected.
