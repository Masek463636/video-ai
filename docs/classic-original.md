# Восстановленный первый стиль

Первый стиль студии использует изолированную копию Python-движка из первого коммита студии `23655c18ee1ab2ca373a0ea5d12b8bf36b8a543c`. Подбор, планировщик, Gemini API, монтаж, субтитры и эффекты взяты из этого снимка без правок. Другие стили используют прежний основной пакет.

Единственное намеренное отличие запуска от ранней студии по просьбе пользователя: вместо двух реакций разрешено до round(длительность / 5), минимум бюджета 3, максимум 8. Это потолок, а не обязательное число. Для 30 секунд допускается до 6 реакций. Они требуют дополнительных запросов по сравнению с вариантом с двумя реакциями. Composition review и поздние поиски замен первого стиля не запускаются.

Это восстановление самой ранней сохранённой студии; точное соответствие конкретному старому MP4 не установлено. Ошибки 503/ограничения API не устраняются откатом. После обновления требуется `python -m pip install --no-deps -e .`, чтобы зарегистрировать дополнительный пакет в editable-установке.
