# Четвёртый стиль: последовательный монтаж

Viral / Darwin использует стоковые футажи и проверенные мемные материалы как отдельные кадры. Мем полностью заменяет изображение на выбранном участке озвучки. Под ним нет стокового кадра; после него продолжается основная видеодорожка. Короткий исходник зацикливается, собственный звук мема отключён.

Подбор Pexels и проверка мемов сохранены. На основе прежнего поиска реакций выбираются подходящие мемные кадры и эмодзи; тайминги привязаны к словам. Видеодорожка режется с точностью до кадра, озвучка и субтитры накладываются один раз после сборки, без изменения их таймлайна.

Поверх видео допускаются только эмодзи. Они меньше прежних крупных мемных вставок, не перекрывают мемные кадры, появляются после короткой паузы от склейки. Ориентир бюджета — один подходящий акцент на 2,5 секунды, а не обязательная квота. Текстовые карточки, предметные PNG, стрелки и круги в этой версии не генерируются.

Искусственные зумы и движения камеры отключены для всех кадров четвёртого стиля. Движение внутри исходного футажа сохраняется. Старый уже отрендеренный base.mp4 может содержать зумы: для результата без них создайте новый ролик.

В студии выберите Viral / Darwin. Флажок реакций включает и мемные кадры, и эмодзи; без него остаются стоки с субтитрами. Первые три стиля сохраняют прежнее поведение.

Диагностика финального этапа: meme-shots.json — отдельные мемные кадры; overlays.placed.json — только эмодзи; shorts_fx/reactions/overlays.json — решения поиска и проверки. Проверка основы сохраняется в base-work/render/composition/review.json. При недоступном Gemini или отсутствии проверенного мема остаётся стоковый видеоряд.
