# Четвёртый стиль: Viral / Darwin

Перенесён из `viral-v1-checkpoint` (9f57d4b). Классический, «Истории и мемы» и «Динамичный» остаются отдельными стилями. Исходная ветка checkpoint сохранена.

В студии выбери **Viral / Darwin — быстрый монтаж и акценты**. Используются те же ключи Gemini и Pexels/Pixabay; Giphy необязателен. Новые платные подключения не нужны для запуска.

## Что делает

- Быстрая раскадровка: ориентир 0,8–1,5 с на сцену, с сохранением смысловых границ.
- Резкие наезды `snap_zoom` и более спокойная каждая четвёртая сцена; мемы не получают дополнительный наезд.
- Крупные реакции из локальных паков, при необходимости Giphy; предметные PNG и числовые акценты из экспериментальной ветки.
- Стрелки и круги для видимой детали: проверяются три кадра, графика заканчивается до смены сцены. При заметном движении цели неподвижный указатель пропускается.
- Векторные стрелки/круги вместо зависимых от шрифтов символов; исправлены испорченные русские подписи.
- Реакции имеют приоритет: другие акценты не накладываются на них по времени.
- Выключение «Реакции и стикеры» убирает все дополнительные акценты, оставляя быстрый видеоряд и субтитры.

## Техническая схема

Студия создаёт основу через `create --viral-style --no-captions`, затем оформляет через `render --editing-style viral --base-video <base.mp4>`. Локатор деталей видит именно ту основу, которая попадает в результат: после расстановки указателей кадры повторно не заменяются. Это отличается от дополнительной проверки видеоряда третьего стиля.

Наезды применяются при создании основы, а не поверх готового видео. При повторном оформлении сохранённого `base.mp4` они не добавляются второй раз. Для другого темпа нужен новый запуск создания основы.

CLI `plan --viral-style` тоже использует быстрый планировщик. `--max-overlays` ограничивает общее число акцентов, включая мемы, PNG и указатели.

Диагностика: `shorts_fx/viral_overlays.json`, `shorts_fx/attention/attention.json` и `overlays.placed.json` в рабочей папке финального этапа. Последний файл показывает допущенные к рендеру акценты. Визуальное соответствие конкретной озвучке требует просмотра результата; автоматическая проверка может ошибаться.

## Читаемый ритм

Перед реакцией новый кадр показывается минимум 0,32 с. Вставка заканчивается за 0,10 с до следующей склейки; слишком короткая реакция пропускается. Указатели после проверки кадров не переносятся по времени. Перед оформлением основа проходит проверку действия и уместности эмоции в контексте всей истории; неподходящий сток получает ограниченный поиск замены. Если проверка недоступна или замены нет, это отражается в `base-work/render/composition/review.json`, исходный кадр сохраняется.
