# Третий стиль: «Динамичный — крупные мемы и реакции»

Основа — `stable-shorts1-good` (6afecc5). Ветка с удачным экспериментом сохранена.
В студии это отдельный пункт `dynamic`; классический и истории используют прежние пути обработки.

## Поведение

- Тот же подбор и кадрирование стокового видеоряда, что в классическом стиле.
- Крупные проверенные реакции по центру верхней области: мемы до 96% ширины / 50% высоты, смайлики до 74% / 42%. Пропорции исходника сохраняются.
- Субтитры с быстрым увеличением 40 → 115 → 100% за 120 мс.
- Планировщик предлагает реакции примерно раз в 3–4 секунды по смыслу, а не обязательную квоту. Не добавляет текстовые плашки и фотографии предметов вместо эмоций.
- Принятая реакция показывается 1,25 с; между вставками минимум 0,2 с. Слишком короткий остаток ролика пропускается. Проверяется реальная длительность, поэтому реакции не перекрывают друг друга.
- Сначала локальные `stickers` / `memes`. Если подходящего материала нет, используется необязательный `GIPHY_API_KEY`. Без него остаются локальные паки.
- Каждый новый кандидат проверяется на читаемость и соответствие. Ошибка проверки отдельного файла не отменяет остальные кандидаты. Принятые реакции не проходят повторное смысловое одобрение при размещении.
- Выключатель «Реакции и стикеры» убирает вставки; пружинящие субтитры остаются.

Большие реакции намеренно могут кратко перекрывать часть верхнего видеоряда — это композиция удачного эксперимента. У классического стиля остаётся его отдельная логика размещения.

## CLI

К существующей команде `render` добавь `--editing-style dynamic`. Для поиска реакций нужны также `--shorts-fx --sticker-dir .\stickers --max-overlays 0`.
`--max-overlays N` задаёт верхнюю границу, 0 — адаптивную. `--composition-review` проверяет основные кадры, но не отправляет принятые динамичные реакции на повторную проверку.

Можно повторно оформить уже выбранные кадры через `--base-video` (нужен caption-free `base.mp4`), сохранив план и транскрипт. Сохранённые реакции из экспериментальной ветки можно использовать через `--overlays-file` вместо `--shorts-fx`.

Диагностика: `shorts_fx/overlays.json` содержит предложения и решения по кандидатам; `overlays.placed.json` — реально допущенные к рендеру вставки. Для Giphy сохраняются ID и исходные ссылки. Ключ в эти файлы не записывается; студия скрывает его в журнале.

## Обновление и запуск в Windows

Останови запущенную студию (Ctrl+C). В папке проекта:

```powershell
git switch story-style-v1
if ($LASTEXITCODE -ne 0) { throw "Не удалось переключить ветку. Сохрани локальные изменения и повтори." }
git pull --ff-only origin story-style-v1
if ($LASTEXITCODE -ne 0) { throw "Обновление не выполнено. Пришли вывод git." }
$videoPython = if (Test-Path .\.venv\Scripts\python.exe) { ".\.venv\Scripts\python.exe" } else { "python" }
foreach ($keyName in @("GEMINI_API_KEY", "PEXELS_API_KEY", "PIXABAY_API_KEY", "GIPHY_API_KEY")) {
    if (-not [Environment]::GetEnvironmentVariable($keyName, "Process")) {
        $savedKey = [Environment]::GetEnvironmentVariable($keyName, "User")
        if ($savedKey) { [Environment]::SetEnvironmentVariable($keyName, $savedKey, "Process") }
    }
}
& $videoPython -m video_ai.web
```

Загрузи озвучку и выбери третий стиль. Giphy показывается в подключениях как необязательный; для старта нужны Gemini и хотя бы один из Pexels/Pixabay.
