# Viral Premium v2

Premium v2 is an isolated opt-in layer built on the saved Viral Premium v1 checkpoint.

Key changes:
- object-aware focus from Gemini subject boxes with OpenCV fallback;
- semantic pace classes: fast, normal, reveal;
- one scene-grammar arbiter for layout, motion and visual-rest rules;
- richer kinetic typography with dedicated number treatment;
- bbox-aware text-behind, parallax/blur layering and subject shadow;
- split layouts: 50/50, 60/40, left/right, PIP and diagonal;
- freeze-frame, spotlight, big-number and stacked-card compositions;
- semantic visual fingerprints for repetition repair;
- word-timed sound cues, risers, music drops and sidechain mix;
- cached Gemini attention/subject decisions and rembg cutouts;
- hand-drawn PNG attention graphics instead of Unicode arrow/circle glyphs.

The old styles and the v1 checkpoint remain separate.
