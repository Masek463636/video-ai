# Пятый стиль — этап 1: общий режиссёрский план

Ветка: fifth-style-v1. Основана на story-style-v1, d9e46f1. Существующая студия с четырьмя стилями остаётся рабочей. Новый стиль пока не предлагается в меню: модуль планирования не является готовым видеомонтажёром.

## Сделано

- fifth-plan читает готовую расшифровку и одним логическим запросом планирует историю целиком: завязку, развитие, контраст, развязку, источник кадра, видимое действие, связь с соседними кадрами, камеру, эмодзи и звук.
- Источники: stock, meme, photo, graphic. Это заявки на подбор, не утверждение, что файл уже найден. Мем — самостоятельный кадр. Эмодзи не накладывается на мем.
- Все слова покрываются ровно один раз. Модель выбирает индексы слов; точные временные границы рассчитываются локально. Отсутствующие/пересекающиеся биты и чужие якоря эмодзи не допускаются.
- Один ограниченный запрос исправления структуры. Неисправимый ответ не сохраняется как готовый план.
- Кэш успешных проверенных ответов по содержимому запроса, конфигурации моделей, температуре и версии схемы. Повторное использование повторно проверяет контракт. Исправленный ответ тоже сохраняется для исходного запроса.
- FifthSession задаёт бюджет логических запросов. После отказа провайдера новые некэшированные запросы сессии прекращаются; уже сохранённые результаты остаются.
- Измеряются логические вызовы, фактические HTTP-попытки, 429, запрошенное время ожидания повторов и usageMetadata токенов. Ключи, тела ошибок провайдера и промпты не пишутся в отчёт метрик.
- Общий клиент Gemini получил необязательные счётчики. Поведение и повторы первых четырёх стилей не менялись.

## Проверка на ПК

В новой ветке, после обычного восстановления ключей:

```powershell
python -m video_ai.cli fifth-plan ".\work-voice5-v1\transcript.json" --work-dir ".\work-fifth-plan"
```

Путь transcript.json здесь пример: использовать существующий файл выбранного прогона. Создаются director-plan.json и gemini-metrics.json. Второй запуск без изменения расшифровки/моделей должен показать cache_hits=1 и logical_calls=0. Кэш по умолчанию: .video-ai-index/fifth/gemini, исключён из Git. Команда пока не рендерит MP4.

## Что выяснено по коду, но ещё не замерено на живом прогоне

Планировщик, выбор фрагментов, проверки композиции и реакции вызывают Gemini отдельно. Один логический вызов может породить несколько HTTP-запросов по моделям и повтор после 429. Счётчик logical_calls не равен API-запросам. Сокращение запросов/времени и повышение художественного качества пока не подтверждены реальными замерами.

## Этап 2: каталог и пакетный выбор (реализован отдельно от рендера)

- `fifth-index` сохраняет описания по SHA-256 содержимого: переименование не вызывает новый запрос, изменение файла требует нового описания, удалённые файлы исключаются. По умолчанию описывает до 24 новых файлов за запуск, по 6 за запрос. Превью создаются только для этих новых файлов; прочие остаются ожидающими.
- `fifth-select` использует существующий поиск Pexels/Pixabay и локальный каталог мемов. Для стоков рассматривает до 6 источников и до 2 окон на источник; до 3 кандидатов на сцену отправляются в Gemini. `--semantic` включает локальное CLIP-ранжирование (при первом использовании возможна загрузка весов).
- Соседние сцены выбираются парами с контекстом истории и предыдущего выбора. Проверяются реальные превью конкретных окон. Сохраняются выбранные источники, тайминги, объяснения и до двух альтернатив.
- Успешные ответы сохраняются; одинаковый повторный запуск использует кэш. Ошибки оставляют сцены нерешёнными, а не подставляют случайный материал. После отказа провайдера новые сетевые вызовы сессии прекращаются.
- Каталог эмодзи готовит данные, но расстановки эмодзи на таймлайне ещё нет. Источники photo/graphic пока остаются нерешёнными. Выбранный сток на этом этапе — превью с сохранённым URL полного видео; загрузка исходника для финального рендера относится к следующему этапу.

Экспериментальные команды (не создают MP4):

```powershell
python -m video_ai.cli fifth-index --meme-dir ".\memes" --sticker-dir ".\stickers"
python -m video_ai.cli fifth-select ".\work-fifth-plan\director-plan.json" --work-dir ".\work-fifth-plan" --semantic
```

Результаты: `selection.json`, `selection-metrics.json`, каталог `.video-ai-index/fifth/assets/catalog.json`. Бюджет выбора — до 12 логических вызовов по умолчанию; реальные HTTP-попытки считаются отдельно. Первый запуск каталога расходует запросы на описания; последующие используют сохранённые описания. Пока нет обещания конкретного времени или экономии токенов: это нужно измерить на реальном материале пользователя.
